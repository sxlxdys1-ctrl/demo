# 超级好玩的小世界 · 手机浏览器先行版

这是根据游戏设计文档制作的手机浏览器游戏。无需安装原生应用；单人进度保存在当前浏览器。好友联机和共享工坊需要部署 `server/` 与 PostgreSQL，部署方法见 [deploy/README.md](deploy/README.md)。

## 已实现

- 3D 方块地形、昼夜变化、挖掘和放置方块；主世界、下界、末地、末地城的探索路线
- 手机触屏摇杆、滑动视角、跳跃和操作按钮
- 8 格快捷栏、80 格背包、中英文物品搜索、生命/饥饿/经验、合成配方
- 五种游戏模式、两种视角、创造模式飞行、生物、战斗和变身
- 免费金币、物品和皮肤商店、8×8 皮肤画板、28 个动作入口、效果模组和三个小游戏房间
- 部署后可注册账号、添加好友、邀请进入世界、同步方块和生物、发布与购买共享作品
- 浏览器本地存档、重新进入时恢复世界
- 键盘辅助操作：WASD 移动、空格跳跃、Q 挖掘、E 放置、I 背包、数字 1–8 切换快捷栏

这仍是扩展原型，未达到设计文档所描述的完整游戏规模：世界范围和生物种类有限，部分配方材料目前无法从地图获取，合成是配方列表而非完整的 3×3 摆放界面，动作和模组效果较简化，小游戏大厅只有三个房间，画和物品展示框尚未实现。当前玩家背包和皮肤存档仍在本机；联机服务器保存共享世界修改、好友关系、账号金币和共享作品。清除浏览器数据会删除本地进度。项目使用原创几何模型和颜色，第三方数据来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 本地开发

需要 Node.js 24 或兼容版本。单人模式：

```bash
npm ci
npm run dev
```

在开发机打开 Vite 显示的网址。若要在手机上通过局域网访问，开发机与手机需处于同一网络，并使用开发机的局域网地址。仓库的 GitHub Pages 工作流会在推送 `main` 后自动发布静态页面。GitHub Pages 自身不运行联机后端；要使用好友联机需另行部署 `server/`。如需让 Pages 页面连接外部后端，构建时设置 `VITE_API_BASE=https://你的游戏域名`，并在服务器允许 GitHub Pages 的来源。

```bash
npm run build
```

## 操作

先点“进入我的世界”。左侧摇杆移动，在右侧画面空白处滑动视角；准星对准方块，点“挖掘”或“放置”。点“背包”可挑选材料并配置快捷栏。游戏会在修改方块和定时自动保存。
