# 超级好玩的小世界 · 手机浏览器先行版

这是根据游戏设计文档制作的手机浏览器游戏。无需安装原生应用；单人进度保存在当前浏览器。好友联机和共享工坊需要部署 `server/` 与 PostgreSQL，部署方法见 [deploy/README.md](deploy/README.md)。

## 已实现

- 3D 方块地形、像素风格纹理、白天 6 分钟与夜晚 7 分钟、夜间使用床等待 10 秒跳过黑夜；挖掘和放置方块及墙面装饰；主世界、下界、末地、末地城的探索路线
- 手机触屏摇杆、滑动视角、准星点选名称、跳跃、直接吃食物、疾跑、蹲下防坠落、丢弃与拾取、打火石点火、坠落与火焰伤害；开始页有醒目的“全屏显示”按钮，游戏右上角也可切换全屏；在游戏画面双指捏合可缩放视野和操作按钮，菜单可分别调整画面及按钮大小
- 10 格快捷栏、400 格背包、中英文物品搜索、生命/饥饿/经验、随身 2×2 合成与放置工作台后的 3×3 合成
- Minecraft 1.21.4 数据中的 1385 种物品和 1557 条合成配方、942 种可放置方块标识；贴图为本项目程序生成的原创图案
- 五种游戏模式、第一/第三/前置三种视角、创造模式飞行、生物、战斗和变身；中文指令支持时间、模式、获取物品、召唤部分生物、传送维度、恢复生命及饱食度
- 免费金币、物品和皮肤商店、8×8 皮肤画板、28 个动作入口、效果模组和三个小游戏房间
- 部署后可注册账号、添加好友、邀请进入世界、同步方块和生物、发布与购买共享作品
- 浏览器本地存档、重新进入时恢复世界
- 键盘辅助操作：WASD 移动、空格跳跃、Q 挖掘、E 放置、F 吃食物、G 丢弃、I 背包、数字 1–0 切换快捷栏

这仍是扩展原型，未达到设计文档所描述的完整游戏规模：世界范围和生物种类有限，部分配方材料目前无法从地图获取；部分复杂方块只以完整立方体显示，物品像素图标与方块纹理是程序生成的原创图案，尚未逐件绘制专属贴图；自由变身中未实现的生物以通用模型显示。中文指令只支持已列出的游戏操作，不能执行任意自然语言需求。动作和模组效果较简化，小游戏大厅只有三个房间，展示框还不能放自选物品。当前玩家背包和皮肤存档仍在本机；联机服务器保存共享世界修改、好友关系、账号金币和共享作品。清除浏览器数据会删除本地进度。第三方数据来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 本地开发

需要 Node.js 24 或兼容版本。单人模式：

```bash
npm ci
npm run dev
```

在开发机打开 Vite 显示的网址。若要在手机上通过局域网访问，开发机与手机需处于同一网络，并使用开发机的局域网地址。仓库的 GitHub Pages 工作流会在推送 `main` 后自动发布静态页面。GitHub Pages 自身不运行联机后端；要使用好友联机需另行部署 `server/`。如需让 Pages 页面连接外部后端，构建时设置 `VITE_API_BASE=https://你的游戏域名`，并在服务器允许 GitHub Pages 的来源。

```bash
npm run build
```

## 操作

开始页可先点黄色“全屏显示”按钮，再点“全屏进入我的世界”；进入游戏后也可点右上角黄色“全屏”按钮。左侧摇杆移动，在右侧画面空白处滑动视角，双指捏合缩放视野和操作按钮；菜单中的“画面距离”和“按钮大小”滑杆可单独调整。准星对准方块，点“挖掘”或“放置”。点“背包”可挑选材料并配置快捷栏。游戏会在修改方块和定时自动保存。
