# 超级好玩的小世界

这是根据游戏设计文档制作的手机浏览器游戏。安卓设备可横屏全屏运行；构建包含离线缓存和安装清单。单人进度保存在当前浏览器，原有存档键保持不变。好友联机和共享工坊需要部署 `server/` 与 PostgreSQL，部署方法见 [deploy/README.md](deploy/README.md)。

目前的 GitHub Pages 地址仍是公开网页，不能保证只有一部手机可访问。私有发布需单独配置受控服务器或向目标设备提供离线安装包；在此之前不要将个人世界存档放入公开仓库或部署资源。手机原版世界存档尚未导入，本游戏也尚不能完整运行基岩版世界和全部原版功能。

## 已实现

- 3D 方块地形、像素风格纹理、白天 6 分钟与夜晚 7 分钟、夜间使用床等待 10 秒跳过黑夜；挖掘和放置方块及墙面装饰；主世界、下界、末地、末地城的探索路线。主世界有煤、铜、铁、金、钻石矿，下界有石英、金矿和远古残骸
- 手机触屏摇杆、滑动视角、准星点选名称、跳跃、直接吃食物、疾跑、蹲下防坠落、丢弃与拾取、打火石点火、坠落与火焰伤害；开始页有醒目的“全屏显示”按钮，游戏右上角也可切换全屏；在游戏画面双指捏合可将视野调至 25%～180%，按钮和快捷栏保持原尺寸，菜单可单独放大按钮，还可开启“俯瞰大地图”
- 10 格快捷栏、400 格背包、中英文物品搜索、生命/饥饿/经验、随身 2×2 合成与放置工作台后的 3×3 合成
- PrismarineJS Minecraft Java 26.1 数据中的 1506 种物品、1684 条工作台配方和 1013 种可放置方块标识；旧存档中的旧版锁链仍兼容。新增内容使用中文名称，贴图为本项目程序生成的原创图案
- 镐子按木/金、石/铜、铁、钻石、下界合金、无尽等级挖掘；挖错材料的工具消耗 2 点耐久，正确使用消耗 1 点，损坏后消失。已实现的无尽工具不消耗耐久；无尽镐、剑、斧、锹、锄、无尽道具和无尽工作台各用 1 块泥土合成
- 剑只有准星对准生物时才能攻击，方块遮挡会阻止命中；手枪和步枪无需子弹。菜单“熔炉与锻造”可烧炼矿石并升级下界合金镐
- 五种游戏模式、第一/第三/前置和地图俯瞰四种视角、创造模式飞行、生物、战斗和变身；中文指令支持时间、模式、获取物品、召唤部分生物、传送维度、恢复生命及饱食度
- 免费金币、物品和皮肤商店、8×8 皮肤画板、28 个动作入口、效果模组和三个小游戏房间
- 部署后可注册账号、添加好友、邀请进入世界、同步方块和生物、发布与购买共享作品
- 浏览器本地存档、重新进入时恢复世界
- 键盘辅助操作：WASD 移动、空格跳跃、Q 挖掘、E 放置、F 吃食物、G 丢弃、I 背包、数字 1–0 切换快捷栏

这仍是扩展原型，不是 Minecraft Java 26.1 的完整复刻：新版本物品、方块和工作台配方已导入，但世界范围和生物种类有限，许多物品只有背包图标、方块模型或合成数据，不能像原版一样使用；部分配方材料仍需创造模式或中文指令获取。复杂方块仍以完整立方体显示，像素图标与方块纹理是程序生成的原创图案。熔炉在菜单中立即烧炼，尚无原版的烧炼进度与燃料时长；下界合金锻造模板可在简化猪灵堡垒领取一次。中文指令只支持已列出的游戏操作，不能执行任意自然语言需求。动作和模组效果较简化，小游戏大厅只有三个房间，展示框还不能放自选物品。当前玩家背包和皮肤存档仍在本机；联机服务器保存共享世界修改、好友关系、账号金币和共享作品。清除浏览器数据会删除本地进度。第三方数据来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 本地开发

需要 Node.js 24 或兼容版本。单人模式：

```bash
npm ci
npm run dev
```

在开发机打开 Vite 显示的网址。若要在手机上通过局域网访问，开发机与手机需处于同一网络，并使用开发机的局域网地址。仓库的 GitHub Pages 工作流会在推送 `main` 后自动发布静态页面。GitHub Pages 自身不运行联机后端；要使用好友联机需另行部署 `server/`。如需让 Pages 页面连接外部后端，构建时设置 `VITE_API_BASE=https://你的游戏域名`，并在服务器允许 GitHub Pages 的来源。

```bash
npm run build
```

`npm run update:minecraft-data` 会从已锁定的 `minecraft-data@3.117.0` 重新生成 Java 26.1 物品、配方、方块和挖掘数据；升级到后续版本时应先更新脚本中的版本号和依赖，再检查配方与规则变更。

## 操作

开始页可先点黄色“全屏显示”按钮，再点“全屏进入小世界”；进入游戏后也可点右上角黄色“全屏”按钮。左侧摇杆移动，在右侧画面空白处滑动视角，双指捏合只缩放地图视野，不改变操作按钮；菜单中的“地图视野缩放”滑杆可调至 25%～180%，“按钮和快捷栏大小”可单独调整到 110%～130%。想一次看更大的地图，在右上角菜单点“俯瞰大地图”；俯瞰时可移动、转向，点右上角“退出俯瞰地图”回到第一人称后再挖掘或放置。准星对准方块，拿合适等级的镐点击“挖掘”；对准生物时用剑或枪点击“攻击/开火”。点“背包”可挑选材料并配置快捷栏。先合成并放置工作台，再制作镐和熔炉；靠近熔炉后从菜单点“熔炉与锻造”烧炼矿石。游戏会在修改方块和定时自动保存。
