# 超级好玩的小世界 · 手机浏览器先行版

这是根据游戏设计文档制作的第一款可玩原型。它直接在手机浏览器运行，无需云电脑或原生应用。

## 已实现

- 3D 方块地形、昼夜变化、挖掘和放置方块
- 手机触屏摇杆、滑动视角、跳跃和操作按钮
- 8 格快捷栏、80 格背包，以及中英文材料搜索
- 浏览器本地存档、重新进入时恢复世界
- 键盘辅助操作：WASD 移动、空格跳跃、Q 挖掘、E 放置、I 背包、数字 1–8 切换快捷栏

目前是单人探索原型。合成、生物、战斗、联机、模组工坊等功能还未实现。存档仅保存在当前浏览器的本地存储中；清除浏览器数据会删除存档。请使用原创美术与名称扩展后续内容。

## 本地开发

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

在开发机打开 Vite 显示的网址。若要在手机上通过局域网访问，开发机与手机需处于同一网络，并使用开发机的局域网地址。正式对外访问需要将 `npm run build` 生成的 `dist/` 部署到 HTTPS 静态网站。仓库带有 GitHub Pages 工作流；在 GitHub 中启用 Pages 的 GitHub Actions 来源后，手动运行一次 **Publish mobile game** 工作流。之后推送到 `main` 会自动发布。

```bash
npm run build
```

## 操作

先点“进入我的世界”。左侧摇杆移动，在右侧画面空白处滑动视角；准星对准方块，点“挖掘”或“放置”。点“背包”可挑选材料并配置快捷栏。游戏会在修改方块和定时自动保存。
