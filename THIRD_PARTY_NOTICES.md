# Third party data

`src/data/items.json` and `src/data/recipes.json` were generated from the
Minecraft 1.21.4 item and crafting data maintained by
[PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data)
(MIT license). Chinese item display names were matched against the 1.21.4
Simplified Chinese language data in
[InventivetalentDev/minecraft-assets](https://github.com/InventivetalentDev/minecraft-assets).

This project uses original geometric models and colors. It does not include
Minecraft textures, sounds, or character artwork. Minecraft is a trademark
of Mojang Studios. This independent game is not affiliated with Mojang Studios.
